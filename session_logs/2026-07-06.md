- **연습장 진입 맵을 lab(보스)→server_hall(재머)로**: "띵띵 보스 경보음" 우회 + 진입 즉시 재머 확인.
  stage 0 유지(막3 시야붕괴 onset이 재머 붕괴와 겹치지 않게).

### 6차 피드백 — 붕괴 반경/중심/디버그 편의
1. **완전 근접 시 시야 반경 늘리기**: 재밍 min radius_near 0.13→0.20(덜 답답).
2. **시야 중심을 화면 중심→플레이어 캐릭터로**: 셰이더에 `vig_center` 유니폼 추가, VeilSight가 매 프레임
   `lerp(0.5, 플레이어 화면UV, vig)`로 설정(캐릭터 몸통 -24 오프셋). 붕괴 시 시야 원이 캐릭터를 따라감.
3. **디버그 매번 켜기 불편**: 에디터 실행 시 자동 해제 — `GameState._ready`에서 `OS.has_feature("editor")`면
   `debug_unlocked=true`. 내보낸 릴리스(웹)는 false라 그대로 잠김(일반 플레이어 노출 방지).
- 검증: radius_near=0.20, vig_center가 플레이어 화면UV 추종(0.5 고정 아님), 에디터 debug_unlocked=true.

### 7차 피드백 — 테두리 시안 / 타원 찌그러짐 / 무적은 연습장 전용
1. **재머 테두리에서 시안 비네트가 강해짐**: 낮은 강도에서 색은 시안인데 불투명도만 올라 그럼. calm_color
   darkening을 `violet*1.6`→`smoothstep(0,0.10,violet)`로 바꿔 재밍 들자마자 어둠으로. 검증: 테두리(jam0.1)
   calm=(0.09,0.01,0.14).
2. **시야 타원이 너무 납작**: 셰이더가 UV(16:9) 그대로 재서 가로로 납작. `aspect` 유니폼 추가, `d.x*=aspect`로
   픽셀 기준 원에 가깝게. 보정으로 가로가 좁아지니 반경 0.20→0.24. (calm/degradation도 원에 가까워짐.)
3. **무적을 설정→연습장으로 + 효과도 연습장 전용**: Settings 디버그 탭에서 제거, `PlaygroundOverlay` 패널에
   토글 추가. `Player.take_hit`이 `debug_invincible and playground_active`로 가드 → 일반 모드엔 절대 영향 없음.
   검증: 일반모드 피격 hp 감소 / 연습장 피격 유지.
