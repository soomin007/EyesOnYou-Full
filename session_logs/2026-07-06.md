### 1차 플레이 피드백 반영 (사용자, 같은 날)
사용자 실플레이 3건 지적 → 수정:
1. **재머 소등이 안 느껴짐** — 화면 안 마커만 꺼져 체감 없음 → 플레이어가 재밍 필드 안이면 **화면 전체
   바이올렛 정적/틴트 오버레이**(`VeilSight._draw_jam_overlay`, 강도=필드 깊이)로 "시야 교란"을 체감시킴.
2. **재머가 VEIL 마커로 잡히는 모순** — VEIL을 눈멀게 하는 게 VEIL 마커로 보이면 이상 → **재머는 마커로 안
   잡히게**(§1 맹점, `_draw`/`_scan_for_call`에서 스킵). 밝은 본체+필드 링으로만 직접 보임.
3. **위장 tell 무의미**(좁아서 보기 전에 리빌 + 둘 다 1방사) → ⓐ `_GlitchTell` 원거리 가독(범위 420→800,
   전신 붉은 플래시) ⓑ 리빌을 근접(120)→**교전(피격/막힘)** 시점으로(근접 폴백 70) ⓒ 참 종류 자폭병→**방패병**
   (HP3, 정찰병 위장 → 정면 사격 튕기며 정체 노출, 1방에 안 죽어 위장이 실제 손해로 이어짐).
- 창모드 재검증: 방패병 위장 스폰·정면 사격 막힘+리빌(hp 유지)·재머 오버레이 무크래시(intensity 1.0) 확인.
- 남음(실플레이): 오버레이 톤/강도, 지직거림 빈도, 방패 위장 난이도.

### 2차 피드백 반영 (사용자, 같은 날)
1. **재머 = 시야 붕괴/블랙아웃처럼** — 별도 바이올렛 정적 오버레이가 틀렸음. 사용자: "베일 없는 시야가
   그 상태(붕괴/블랙아웃)가 기본." → 재설계: 모델을 "적이 필드 안"→**"플레이어가 필드 안=VEIL 없음"**으로
   바꾸고, 기존 **붕괴 비네트(`_update_vignette`)를 재밍 깊이만큼 재사용**(어둠+시야 축소, 라이벌은 살짝
   바이올렛) + 마커가 깊이만큼 사라짐(`_player_jam_intensity`). 재머는 마커로 안 잡힘 유지. 바이올렛 정적
   오버레이·적 기반 `_jammer_suppressing` 폐기. 창모드 검증: 필드 중심 vig=1.00 / 밖 vig=0.00.
2. **위장 지직거림 크기·강도** ↑ — `_GlitchTell` 전신 플래시 크기 ~30%↑(±16→±21, 높이 46→56),
   알파/선 굵기 상향, 원거리 최소 강도 0.45→0.55.

### 3차 피드백 반영 (사용자, 같은 날) — 재머 붕괴가 실제론 약했음
사용자: "보라색으로만 변하고 붕괴 안 됨 + 범위 안 마커 그대로." `gh run list`로 배포 성공 확인(스테일 아님) →
**코드 버그**. 원인: 강도=거리 선형감쇠 + vig 램프 0.7s인데 플레이어가 필드를 빠르게 통과 → vig가 낮게만
올랐다 내려감(옅은 틴트). *2차 검증이 플레이어를 중심에 고정해 vig=1.0을 봐서 놓침* — 하니스가 이동을
시뮬레이션해야 했음(known_issues 추가). 수정: ⓐ 강도를 반경 대부분에서 평탄화(바깥 35%만 감쇠) ⓑ 재밍 진입
시 vig 램프 5.0으로 가속 ⓒ 재밍 어둠 강화(0.66→0.82). **통과 시뮬 재검증: max_vig=1.00, vig≥0.7이 ~2.2초.**
