## 결정 사항
- **ⓐ datacenter=재머(위장 아님)**: 막3 s6 전투 3맵 중 datacenter만 라이벌 요소가 없었음. 위장은 waves 모드에서
  `_spawn_deceits`가 스킵돼 코드 필요 → 저마찰 선택으로 재머(enemies dict만으로 동작). ARENA는 통과형과 달리
  "갇혀 싸움"이라 ENEMY_CLEAR=반드시 처치 → "우선 표적" 강제, 같은 메커닉의 새 쓰임새.
- **재머는 최종 웨이브에**: server_hall "후반 클러스터 옆" 배치 패턴을 아레나로 옮김. 절정 근접 웨이브를 가려
  드라마 + 좌측 bomber는 반경 밖(비대칭 안전지대 = fair).
- **위장 함정은 server_hall에(control_corridor 아님)**: control_corridor엔 이미 위장 적. 한 맵에 deception 2개는
  "드물어야 무섭다"(§4.1) 위반 → 타입을 다른 맵에 분산해 맵당 deception ≤1 유지. 재머는 §3 정직-블랙아웃이라
  deception으로 안 셈.
- **위장 함정 = 위장 적의 함정 버전**: `_GlitchTell`을 가로 밴드로 변형, 같은 §4.1 공정 규칙(항상 tell / 신뢰가
  리빌 반경 / 밟으면 실제 피해). 시각만 숨기고 데미지는 진짜라 "속았다=내 부주의" 유지.
- **`_traps_present` 미설정**: 위장 함정에 "못 잡는 함정" HUD 경고를 붙이면 은닉이 깨짐 → tell이 유일한 경고.
