## 세션 2 (오후) · 실플레이 피드백 6건 반영 + 설계 미결 2건

### 요약

사용자 실플레이 피드백 7건을 받아 원인을 코드에서 특정한 뒤 6건을 고쳤다. 핵심 교훈은
"지적된 기믹이 범인이 아닌 경우가 둘이나 있었다"는 것 · 지하철은 열차가 아니라 평면 배치가,
통제 회랑은 판정 버그가 아니라 존이 화면에 없던 것이 원인이었다. 남은 2건(위험/보상 체계
재설계 · 다회차 보스 난이도)은 방향 결정이 필요해 백로그로 넘겼다.

### 주요 변경

- `MapData.gd`: 지하철 방2 재설계(승강장 단 560/600/520 + 발디딤 3 + 승강장 저격 2 +
  지상 순찰 벽감 시작) · 통제 회랑 방3 안내 자막 재작성 · 금지 조어 "격벽" 2건 교체.
- `Enemy.gd` / `TrainHazard.gd` / `Stage.gd`: 환경 처치 무보상 경로(`env_killed`,
  치명 시에만 유지 → 살아남으면 즉시 해제). 킬 시그널 배선을 `bind` 고정에서 런타임 조회로.
- `RouteData.gd`: skilled 추천 동점 규칙 반전 + 전 모드 공통 `_undominate` 사후 가드.
- `Stage.gd`: 검증 구역 시각(`_build_mid_gate_zone` 바닥 도료 3단·경계 마크·남은 경비 표기,
  개방 시 페이드) · `_keep_in_gate_zone`(risk 배율 스폰 존 클램프) · 창고 상자 3방 톤·밀도.
- `ChaseHazard.gd`: y_up 맥동(`_surge_factor` 버팀/붕락 · 평균 보존) + 붕락 굉음·흔들림·잔해.
- `CoreTunnel.gd`: 다회차 건너뛰기(`playthrough_count >= 1` + `ui_skip`) · 타이머 체인 가드.
- `docs/dialogue/`: route_lines 누락 9건 수록 + 변경 2건 동기화.

### 결정 사항

- **환경 처치는 무보상**. 열차가 자동으로 치우고 XP까지 주면 "서서 기다리기"가 최적 플레이가
  된다. 해저드에 밀어 넣어 얻는 것은 안전이지 경험치가 아니다(경보 진압 경비 무보상과 동형).
- **적을 세이프존에서 시작시킨다**. 광역 해저드 방에서 적이 사정권에 통째로 있으면 방이 자동으로
  빈다. 플레이어가 끌어내야 해저드에 닿게 해야 "전술"이 된다.
- **추천은 사후 필터로 지킨다**. 점수식을 고치는 것만으로는 가중치를 손볼 때마다 열세 카드
  추천이 재발한다. 선택 후 지배 관계 검사를 별도로 둔다.
- **맥동은 평균 속도를 보존한다**. 붕괴 체감만 바꾸고 등반 여유·max_gap 밸런스는 건드리지 않음
  (실측 평균 81.4 vs 설계 82).
- 검증 구역 표기를 넣자 가드가 7기로 드러났다(risk3 배율 + 존 클램프). 수치는 유지하되
  실플레이에서 과한지 확인 대상.

### 미해결 / 다음 할 일

- 실플레이 재확인 6건 전부(특히 지하철 방2 리듬 · 붕괴 맥동 체감 · 검증 구역 가드 7기 난이도).
- **위험/보상 체계 재설계 방향 결정**: risk/reward가 1:1 상관이라 두 축이 정보를 못 준다.
  후보 ⓐ 값 재배분 ⓑ 보상 축을 종류로 교체 ⓒ 축 폐기 후 성격 태그. 상세 = backlog.
- **다회차 보스 난이도**: 권고는 숫자 상향 반대 · 라이벌 기억 축(C)에 얹은 패턴 변주.
