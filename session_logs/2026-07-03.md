## 요약
진짜 기믹 맵 스트림을 이어, 아레나 방어 기믹('반응로 제어실')을 신규 프리미티브+맵으로 제작. 지켜야 할
코어를 침입 dome로부터 방어하는, datacenter(자유 사냥 kill-all)와 정반대의 "고정 방어" 손맛. 적 AI는
전혀 건드리지 않고(플레이어 추격 그대로) 코어 곁에 서면 적이 몰려드는 구조로 성립.

## 결정 사항
- **적을 코어로 강제 유도하지 않는다(AI 무변경)** — `_find_player`를 쓰는 수십 개 경로를 재작성하는 리스크
  대신, "코어 dome 안 적 수만큼 드레인" + "플레이어가 코어 곁에 서면 적이 자연히 몰림"으로 방어 성립.
  최근 기믹 맵들의 '작은 프리미티브 1개' 패턴 유지.
- **침입 판정 = 수평 반경 + 지면 밴드** — 높은 발판 저격/드론이 코어를 안 깎게(dy로 제외) 해 "근접=코어 위협,
  원거리=플레이어 압박" 역할 분리를 자연히 구현. 반경만 쓰면 대각 거리로 저격도 걸려 역할이 뭉갬.
- **클리어=웨이브 전멸(ENEMY_CLEAR 재사용), 실패=코어 함락** — 기존 웨이브/아레나 클리어 로직 그대로 쓰고
  코어는 "실패 조건"만 얹음. 함락은 사망 경로(register_death→Death 씬 재시도) 재사용.
- **ARENA 배경은 전용 ambience로** — `_build_indoor_backdrop`가 HORIZONTAL 전용이라, ARENA 방어 맵의
  시그니처 배경은 `_ambience_reactor`에서 직접 그림(공유 게이트 무수정). [[new-map-always-full-background]].
- 검증: import(DefenseCore 등록) + 창모드 래퍼(`_core_check.tscn`) — (A) 실제 Stage 부팅으로 코어/웨이브/
  goal 생성 확인, (B) 격리 코어로 드레인·밴드 판정(수평/dy 밖 제외)·브리치·secured를 수동 `_physics_process`
  스텝으로 결정적 검증. 검증 후 임시 파일 삭제.

## 오류/함정 (known_issues 반영)
- **`bool(null)` = "Nonexistent 'bool' constructor" 크래시.** `bool()` 자체는 정상이나 인자가 null이면 죽는다.
  `Object.get("prop")`는 없는 속성에 default 없이 null 반환 → `bool(node.get("harmless"))`가 harmless 없는
  노드에서 크래시. `--import`는 통과, **창모드 부팅에서만** 잡힘(함수 본문 런타임 에러는 import가 놓침).
  → 존재 불확실 속성은 `if node.get("prop"):`(truthiness, null=falsy)로.
