  전환 = 클라이맥스 임팩트. 비트(걷기→점등→목격→선택)는 렌더러와 분리, 소실점 2D 후퇴 가능.
- **14-1 = 3페이즈 + 가짜 클리어** (사용자: "2페이즈가 끝인 척하면서 거짓 베일이 나와서 한 번 더")
  — P1 군대 지휘(엘리트 웨이브+재밍) → P2 시설 빙의(포탑·격벽·소등·함정) → 가짜 클리어(클리어
  UI 자체를 속임수로) → P3 거짓 VEIL 분신전(가짜 마커·무표시 위협, trust가 개입 빈도 = 전투력).
  상세 = rival_veil_concept §7.2 신설.
- **라이벌 말투 = 후보 A(결이 어긋난 정중함) 확정** — dialogue_review 결정란 기입.
- **VEIL 어투 = 전투 콜아웃만 보고체** — 브리핑·서사는 신뢰 밴드 아크 유지("일할 때는 프로").
- 구현 순서 제안: 14-2 터널 프로토(손맛 먼저) → 14-1 P1~P2 → 페이크아웃+P3 → 회수 문서
  리디자인 → 대사·BGM. BGM: 14-1=Violet Signal 유지, 14-2=무음+환경음 후보.
