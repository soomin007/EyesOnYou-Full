# 2026-08-12 세션 로그

## 요약
최종 보스 스테이지 2막 구성의 1단계 = 14-2 코어 대면 터널 프로토타입(2.5D 유사 1인칭) 구현.
회의 확정(어제 세션 5) 스펙대로 비트(걷기→순차 점등→코어 목격→선택)를 렌더러와 분리해 짰고,
연습장 진입 버튼으로 손맛 검증이 가능한 상태까지. 창모드 하니스 + 스크린샷 검증 완료.

## 주요 변경
- `scripts/CoreTunnel.gd`(신규) — 비트 컨트롤러 + `_TunnelView` 렌더러(내부 클래스, 소실점 원근
  투영 `_draw`). 걷기(관성·헤드밥·발소리), 순차 점등(전방 820 트리거 + 0.5s 캐스케이드 + 점등
  플리커·시야 충격, hatch_open 대타), 코어(바이올렛 헤일로 + 시안 심장 + 케이블 수렴 + 바닥 반사),
  목격 비트(z4040 강제 정지 + smoothstep 줌 + 세계 감광), 종료 패널(처리 선택 미리보기 · 다시 걷기 ·
  타이틀로). BGM 정지(무음+환경음 사양). 터치 = 화면 좌/우 절반 홀드. ESC/P = 타이틀 복귀.
- `scenes/core_tunnel.tscn`(신규) — Control 루트 최소 씬.
- `scripts/SceneRouter.gd` — CORE_TUNNEL 상수 추가.
- `scripts/PlaygroundOverlay.gd` — "14-2 터널 프로토 (유사 1인칭)" 진입 버튼(종료 버튼 위).
  진입 시 playground_active 해제(플래그 누수 차단).
- `docs/design/backlog.md` — 구현 순서 ① 완료 기록.

## 결정 사항
- **비트 ↔ 렌더러 분리 구조** — 회의 결정("손맛이 안 나오면 소실점 2D 후퇴") 그대로. 컨트롤러는
  상태(player_z·전등·코어·밥)만 갖고, `_TunnelView`는 그 상태를 읽는 순수 뷰. 교체 지점 명확.
- **점등 리듬은 진행이 이끈다** — 시간이 아니라 player_z + 820 트리거(항상 한 걸음 앞을 비춤).
  빨리 걸어도 0.5s 캐스케이드 최소 간격으로 텅…텅…텅 리듬 유지. 하니스 실측 간격 ~2.7s(걸음 주도).
- **프로토는 실런 비오염** — 처리 선택 미리보기는 DisposalChoiceOverlay를 그대로 띄우되 선택을
  GameState에 저장하지 않음. 모든 퇴장 경로는 Title(reset) 경유.
- **SFX는 기존 자산 대타** — 점등=hatch_open, 목격=arcturus_enter. 전용 환경음(점등 텅·심박)은
  구현 순서 ⑤(대사·BGM 단계)에서.
- PATCH_NOTES는 갱신 안 함 — 연습장 전용 디버그 프로토라 플레이어 대상 내역이 아님.

## 검증 (창모드 하니스 + 스크린샷)

  fade_in→walk→witness→done · 종료 패널 생성 · core_vis 1.0 — 전부 PASS.
- 스크린샷 4장: 첫 점등(복도 원근·바닥 풀빛) · 중반(전등 열) · 목격(코어 헤일로+줌) · 종료 패널.
- 헤드리스 import(클래스 등록) + 씬 직접 부팅 스모크 클린. 임시 하니스 파일 삭제 완료.
