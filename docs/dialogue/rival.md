나온다. 전투 중 콜아웃·조언·route_lines는 기존 자막 유지.

## 10. 부속 표기·메커니즘 노트(번역 시 참고)

- **보스 바 이름 라벨**: P1·P2 목표 바와 P3 눈 체력 바의 화자 표기는 텍스트 `?` 하나
  (`Stage.gd` `_build_rival_node_bar` / `_build_fv_bar`). 번역 불필요.
- **루트맵 유인 표시 형식**: `?   ` 접두 + 유인 멘트(`RouteMap.gd` `_update_info` 계열,
  `"?   " + rival_rec_line`). 접두는 서식이라 번역 불필요.
- **14-1 내 VEIL 억압**: 가짜 클리어 이후(`_rival_phase >= 2`) 내 VEIL 자막은 1.4s로 강제
  단축되어 타이핑 도중 끊긴다(통신 두절 연출, `Stage.gd` `_show_veil_subtitle`의 choked 분기).
  온전한 문장은 보라(라이벌)만. 별도 문자열 없음.
