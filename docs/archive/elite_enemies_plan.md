## 0. 설계 원칙 (기존 교훈 반영)

1. **HP 스택보다 "항상 유효" 강화 우선.** known_issues 교훈("데미지 +N은 적 HP 분포에 막힌다")의
   거울상: 적도 HP만 올리면 플레이어 데미지 2(막4쯤 대부분 보유) 기준 홀짝에 따라 체감이 사라진다.
   엘리트의 위협은 템포·행동(속도, 사이클, 2연 투하)이 주역, HP는 "한 대 더" 수준의 보조.
2. **텔레그래프 시간은 건드리지 않는다.** §4.1 fair 원칙: 회피 창(patrol 텔레그래프 0.45s, bomber
   무장 0.7s, sniper 조준선)은 인지 계약. 엘리트는 텔레그래프 이후·사이 구간(돌진 속도, 회복 시간,
   발사 간격)을 조인다. risk3의 텔레그래프 0.6배 단축과 중첩 방지: 엘리트는 텔레그래프 배율에 손대지 않음.
3. **정체성 보존.** 각 적의 "정답 행동"(bomber=멀리서 1샷, shield=측면, sniper=LoS 끊기)이 엘리트에도
   그대로 통해야 한다. 정답을 무효화하는 강화(예: bomber HP 3)는 금지.
4. **크기 불변.** visual.scale·콜리전 shape.size 분리 함정을 아예 회피: 엘리트는 크기를 안 키우고
   장식·오라로만 구별.

## 3. 시각 언어: "바이올렛 계급장" (라이벌 군대 설정으로 확정, 2026-08-10)

- **서사 = 색**: 엘리트는 라이벌이 물들인 개체이므로 **라이벌 바이올렛(0.72, 0.42, 1.0 축)**.
  초안의 엠버(시설 정예 해석)는 설정 확정과 함께 폐기 — "같은 진영 = 같은 색"이라 오독 우려 자체가 해소.
- 바이올렛 3용법은 색이 아니라 **형태·시간성**으로 구분:
  - 거짓-렌더 tell(`_GlitchTell`) = 붉은-바이올렛 **지직임**(순간·불규칙 점멸)
  - 재머 = 바이올렛 **공간 필드**(영역 효과)
  - 엘리트 = **항상 켜진 고정 기하** — 머리 위 셰브론 계급장(2단) + 발밑 가는 링. 깜빡이지 않음.
  → "지직이면 거짓, 고정 기호면 정예"로 문법화. 위장 스폰 엘리트 금지 규칙(§1)이 "위장한 적이
  계급장을 다는" 모순도 함께 차단.
- 형태는 shiny(골드, 부드러운 원형 펄스)와도 색+기하 이중 차별화.
- 구현: modulate 함정 회피 = `_ShinyAura`·`_JamField`와 동형의 독립 자식 Node2D(_draw) `_EliteCrest`.
  텔레그래프·피격 플래시가 modulate를 리셋해도 계급장 불변. shiny와 동시 발현 허용(둘 다 독립 자식).
- 조준선·텔레그래프 색은 기본형과 동일(위험 문법 일관성 우선, 구별은 계급장 전담).
- 첫 조우 VEIL 반응 방향(문구는 사용자 영역): "다른 신호를 받는 개체" — 라이벌 군대 복선.

## 4. 스폰 규칙

방식: **확률적 승격(스테이지 램프) + MapData 오버라이드**. `_spawn_enemy` 진입 시 롤.
확률형이어야 risk 배율 복제분에도 자연 적용되고 맵 데이터 수정이 최소.

| 스테이지 | 승격 확률 | 의도 |
|---|---|---|
| s0~s8 | 0% | 데모 영역 보존(대비 원칙) |
| s9 | 5% | 첫 노출(기믹 학습 맵이라 실질 0~1기) |
| s10 | 12% | |
| s11 | 18% | 막4 고조 |
| s12 | 30% | 막5 "흔하게" |
| s13~14 | 기본 미적용 | 대본 스테이지. 향후 14-1 보스 미니언에 명시 적용 검토 |

- risk3이면 +5%p(개체수 배율로 모수가 이미 늘어나므로 소폭).
- 맵당 상한: 막4 = 2기, 막5 = 4기(전원 엘리트 클러스터 차단 안전핀).
- MapData `elite_chance`(float) 오버라이드: unfair 맵(예: collapse 강제 전진 중 shield 엘리트) 0 잠금,
  세트피스 확정 배치는 후속.
- 공정성: 계급장 상시 노출 + 첫 조우 도감 카드 1회 + VEIL 한 마디(문구는 사용자 영역).

## 5. 도감

타입별 카드 대신 **단일 카드 1장**: id `"elite"`, 이름 "강화 개체". 블러브 방향(문구는 사용자 영역):
"보랏빛 계급장을 단 개체. 다른 신호를 받는다. 더 빠르고, 더 오래 버틴다. 상대하는 법은 같다."
`Enemy._check_first_encounter`에서
elite이고 첫 조우면 표시. 기반 타입 카드와 동시 신규면 기반 타입 우선(카드 2연속 방지).
`_enemy_id()`는 기반 id 그대로(기존 소비처 불변), elite는 별도 플래그.
