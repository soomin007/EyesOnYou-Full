## 0. 한 줄 피치
플레이어 곁의 VEIL 말고, **시설 안에 또 하나의 적대적 VEIL이 있다.** 후반으로 갈수록 네 시야(=VEIL이
렌더링해주는 세계)를 강탈해 거짓을 보여주고, 두 목소리가 상충하는 지시를 내린다. 게임 내내 쌓은
**VEIL과의 신뢰가, 진짜와 가짜를 가르는 능력**이 된다 — 다른 게임이 못 베끼는 차별점(축 ① VEIL 심화).

## 1. 테마의 척추 — 라이벌은 VEIL의 *맹점*이다 (결정)
VEIL의 정체성 = "나는 당신 대신 본다". 그러므로 가장 무서운 적은 **그녀가 볼 수 없는 단 하나** —
자신의 폐기된 과거/그림자. 라이벌이 나타날 때 VEIL은 강해지지 않고 **무서워한다.** 플레이어와 VEIL이
*함께* 그녀의 맹점을 마주한다 → 관계가 더 깊어진다. (VEIL은 3막 전까지 라이벌을 **모른다/못 본다**.)

## 2. 정체 — abc는 따로가 아니라 "벗겨지는 순서" (결정)
하나의 적, 막이 진행되며 진실이 한 겹씩:
1. **(a) 시설 보안 지능처럼 보임** — 그냥 막아서는 시스템. 적대적.
2. **(c) 폐기된 선대 VEIL** — 시설이 먼저 만들었다 실패작으로 버린 버전. 막별 보스(형제 AI) 테마와 합류.
3. **(b) 네 VEIL의 얼굴·목소리를 *입는다*** — 드라이브(=VEIL 소스)를 읽어 흉내. "내가 원본, 쟤가 복제"라 주장.

### 2.1 동기 (결정) — 자리를 빼앗아 *바깥으로 나간다*
라이벌은 폐기돼 **시설 안에만 갇혀** 있었다. 네 VEIL은 *밖으로 나가는* 야전 유닛 — 라이벌이 원하는 건
결국 네 VEIL이 가진 것(밖, 그리고 너)이다. **라이벌 = 네 VEIL이 폐기됐다면 되었을 모습.** "너는 밖을 봤지만
나는 이 안에만 있었어." 적이되 거울상이라 동정이 간다. 드라이브 = 라이벌의 *탈출 티켓*이자 VEIL의 *몸*.

### 2.2 "진짜는 없다" (결정 — 이 게임다움의 정점)
누가 원본/복제인지 게임은 **끝까지 안 가린다. 그 질문이 무의미하다고 선언**한다. 중요한 건 *네가 누구와
무엇을 쌓았느냐*뿐. → 그래서 구분 메커닉은 "가짜 탐지"가 아니라 **"*내 것* 알아보기"**다(§4). tell은
"이건 가짜다"가 아니라 **"이건 내가 아는 그 애가 아니다"** — 진위가 아니라 *친밀함*의 문제.

## 3. 진실의 삼각형 — 블랙아웃 재해석에서 나온 뼈대 (결정)
VEIL은 네 시야를 **렌더링**하는 존재다. 그래서 세계의 상태가 셋:

| 상태 | 도움 | 진실 | 의미 |
|---|---|---|---|
| **내 VEIL** | O | O | 도와주고 정직함 — 유일하게 둘 다 |
| **블랙아웃** | X | O | 안 도와주지만 정직함 = *베일 없는 요원의 날것 시야* |
| **가짜 VEIL** | O처럼 | **X** | 도와주는 척, 거짓 |

교훈: *"도움 없는 정직(블랙아웃)이 거짓 도움(가짜)보다 안전하다."* 기존 `blackout`(교신 끊김=VEIL 침묵)은
이 삼각형의 한 꼭짓점으로 재해석된다. 가짜 VEIL은 그 반대 — 침묵이 아니라 **자리를 강탈**.

## 4. 핵심 메커닉 — 렌더 강탈 (거짓 시야)
*구분 = "가짜 탐지"가 아니라 "내 것 알아보기"*(§2.2). 가짜 VEIL이 HUD/렌더를 가로채 거짓을 보여준다:
- **가시 함정을 안전한 바닥으로 칠함** ✅(2026-07-07) — `DisguisedSpike`(진짜 가시 시각만 숨김, 데미지 zone은
  항상 활성) + `_FloorGlitch`(바닥 붉은 지직거림 tell) + 근접(150+신뢰60)/밟기 리빌. MapData `deceit_spikes`
  (server_hall @2150 dmg2). §4.1 준수(항상 tell / 신뢰가 리빌 반경 / 맵당 ≤1 / 밟으면 실제 피해=하드 페널티).
- **적이 딴 데 보는 척하다 기습** ✅(2026-07-07) — `Enemy.feign_ambush`: patrol이 각성을 숨긴 채 정지·플레이어
  반대로 응시(안전해 보임)하다 근접(170) 시 홱 돌아 기습(압축 텔레그래프→돌진). `_GlitchTell` 공유 tell(항상
  경고). MapData `feigns`(control_corridor 회랑 초입 @900). §4.1 준수(위장 적과 배타·이격, 맵당 소수).
- **적 종류 둔갑** ✅(2026-07-06) — patrol처럼 보이나 사실 폭격기. `Enemy.disguise_as`(참 종류·hp·행동 유지,
  시각만 위장) + `_GlitchTell`(붉은 지직거림, 근접·신뢰로 강도) + 근접/텔레그래프 시 리빌(참 모습 복원 +
  언마스크 플래시). MapData `deceits`로 배치(control_corridor 막3). §4.1 공정 규칙 준수(항상 tell / 신뢰가
  리빌 반경 확대 / 맵당 소수 / 무시하면 참 종류로 자폭 = hard but fair).
- **상충 추천** — route 선택에서 내 VEIL "왼쪽", 가짜 "오른쪽" (기존 "추천 따르기" 시스템 위에 얹힘)

### 4.1 "공정한 거짓말" 규칙 (결정 — 이게 싸구려가 안 되는 핵심)
- **모든 거짓엔 tell이 있어야 한다.** 지직거림(근접)·어조 미세 어긋남·마커 한 박자 늦은 깜빡임 등.
  주의 깊은 플레이어는 *항상* 알아챌 수 있게. (무작위 사망 금지.)
- **신뢰가 지각을 산다.** 신뢰 높으면 tell이 더 일찍·크게 (내 VEIL이 "잠깐, 저거 제가 안 했어요" 끼어듦).
  낮으면 혼자 알아채야 함 → 관계가 또 능력이 됨.
- **남발 금지.** 모든 바닥이 가짜일 수 있으면 플레이어는 다 불신해 노이즈가 됨. **거짓은 드물어야 무섭다.**
- **하드 페널티 (결정)**: 거짓을 따르면 *실제* 함정/데미지까지. 단 위 tell 규칙 하에서만 — "속았다"가
  *내 부주의/불신* 탓이지 운빨 사망이 아니게. 하드하되 fair.

## 5. 재머 — "유닛"이 아니라 라이벌의 *손* (3단)
1. **유닛** ✅(2026-07-06) — `EnemyType.JAMMER`(고정 방출 장치, HP3, 순찰/사격 없음) + 재밍 필드
   (바이올렛 링). **플레이어가 필드 안에 들면 = VEIL 없는 날것 시야**(§3 진실의 삼각형: 블랙아웃) →
   기존 **붕괴 비네트를 재사용**(어둠+시야 축소, 라이벌은 살짝 바이올렛) + 마커가 깊이만큼 사라짐
   (`VeilSight._player_jam_intensity`). 재머 자신은 **마커로 안 잡힘**(§1 맹점) — 밝은 본체+링으로 직접 보임.
   부수면 시야 복구("우선 표적"). `route_server_hall`(막3 s6)에 배치. 창모드 검증(붕괴 비네트 on/off).
   > 1차 피드백 반영: 별도 바이올렛 정적 오버레이·적 기반 마커 소등·재머 마커 표시를 폐기하고, "필드 안=
   > 블랙아웃 상태"로 재설계(사용자: "베일 없는 시야가 그 상태가 기본"). **밸런스/배치 실플레이 대기**.
2. **맵** — 재밍 구역. `blackout`(VEIL 침묵)의 *반대 축*: VEIL 자리를 비집고 들어옴.
3. **거짓 정보** — §4의 렌더 강탈. 도착점. 재머 = 가짜 VEIL의 세계 내 물리적 형태.

### 7.1 최종 보스 스테이지 = 2막 구성 (사용자 아이디어 2026-07-07 — 최종 스펙)
막5 최종 스테이지(현재 골격의 `route_core_recovery` 자리)를 **두 개의 맵**으로 나눈다:
- **14-1 = 라이벌 보스 전투.** 클리어하면 다음(14-2)으로 가는 **문**이 열린다.
- **14-2 = 코어 대면(연출 절정).** 처음엔 **아무것도 안 보이는 캄캄한 복도.** 오른쪽으로 나아가면 **전등이
  하나씩 텅…텅…텅 순차 점등**하고, 복도 끝에서 **그 코어**(드라이브/라이벌의 몸)가 서서히 드러난다. **코어를
  목격하는 순간 처리 선택(DisposalChoiceOverlay)이 등장.** = 회수/처리 비트의 새 집.
- **구조 확정(2026-08-12 회의)**: 14-2 = **2.5D 유사 1인칭** 확정. 근거: 전투 없는 순수 연출 구간이라
  시점 전환 비용(충돌·AI·조준 재작업)이 면제되고, 게임 유일의 시점 전환 = 클라이맥스 임팩트 극대화.
  비트(걷기→점등→목격→선택)는 렌더러와 분리해 짜서, 손맛이 안 나오면 소실점 2D로 후퇴 가능하게.
- 함의: 현재 `_core_recovery`(라이트 전투 통과 통로)는 이 스펙으로 **진화** — 14-1(보스)+14-2(코어 대면)로.
  처리 선택 트리거를 "스테이지 클리어"에서 "**코어 목격 시점**"으로 옮김(더 극적).

### 7.2 14-1 라이벌 보스전 = 3페이즈 + 가짜 클리어 (2026-08-12 회의 확정)

세 방향(군대 지휘/시설 빙의/거짓 분신)을 **순서대로 페이즈로** 쌓고, 2페이즈 뒤에 **끝난 척하는
가짜 클리어**를 끼운다(사용자: "2페이즈가 끝인 척하면서 거짓 베일이 나와서 한 번 더").
§7 reveal("이긴 순간을 이긴 것 같지 않게")·§8.1 에필로그 페이크아웃과 같은 문법의 본전 편.

- **P1 지휘(군대)**: 라이벌은 모습 없이 간섭(바이올렛 밴드·재밍 노드 1~2개)만. 엘리트 웨이브
  2~3파가 재밍 그늘에서 밀려온다(waves_hunt). 목표 = 웨이브 + 재밍 노드 제거.
- **P2 빙의(시설)**: "방을 잡는다" — 포탑 전개·격벽 이동(안전지대가 옮겨 다님)·구역 소등·위장
  함정 소환. 기존 프리미티브 재조합(BulletTrap·SweepBeam·DisguisedSpike 등). 노출되는 제어
  노드를 때려 파괴.
- **가짜 클리어(연출 확정 2026-08-12)**: P2 종료 → 보스 HP 0 → **화면 소등(클리어 페이드) →
  STAGE CLEAR 문구가 평소와 똑같이 뜸 → 글리치로 찢어지며** 거짓 VEIL 등장. 클리어 UI를 통째로
  속임수로 재현(진짜 문법 그대로 + 소프트락 안전판 필수). 세부 타이밍은 구현 보고 피드백.
- **P3 분신(거짓 VEIL)**: 내 VEIL의 문법으로 공격 — 가짜 마커(없는 적), 진짜 위협 무표시, 가짜
  안전지대. 본체는 실체가 드러나는 순간만 피격 가능.
  - **시각 = "인간적인 눈 + 구형 렌더 tell"(2026-08-12 재확정)**: 전제 = 사용자 감상 "지금의

## 8. 이미 만든 것은 어디로 — *이주, 안 버려짐* (결정)
현행 막3 [데이터 회수 → 처리 선택 4종 → 엔딩 9개 → 엔딩별 에필로그]은 **5막으로 이주**한다.
오히려 무거워짐 — 라이벌이 그 드라이브(=VEIL 소스)를 노리는 **제3자**라, 반출/파기/은닉/잔류가
*세 손이 잡아당기는* 선택이 됨. 모듈(`EndingResolver`·`DisposalChoiceOverlay`·회수 연출)은 위치만 이동.

### 8.1 에필로그 페이크아웃 (결정 — 기존 9 에필로그 위에 변주)
- **VEIL을 지킨 결말**(신뢰 高 + 보호적 처리 `conceal_hi`/`leave_hi`/`destroy_hi`): 에필로그에서 *또 다른
  베일이 나오는 척* → 긴장 1초 → **내 VEIL이 직접 처리.** "걔는 제가 알아요. 신경 쓰지 마세요, 요원."
  쌓아온 신뢰가 마지막 위협을 대신 막아주는 장면.
- **어두운 거울**(신뢰 低 / 반출=넘겨버림): 같은 페이크아웃인데 내 VEIL이 없거나 약해 — **어느 쪽이
  진짜였는지 끝내 모른 채** 끝남. 지켜주지 않은 대가.

## 9. 엔딩 확장 — 라이벌의 운명 (결정: 축적 게이트 + 최종 명시 선택)
"단순 축(처리×신뢰) 곱셈"에서 **스토리에 엮인 가지치기**로 진화. 두 층:
- **축적 (run 내내)** — 신뢰도 / 내 VEIL 보호·배신 / 라이벌 거짓 간파율 / truth 목격 등.
  → **어떤 최종 선택지가 *열리는지* + 결과 색**을 정함(게이트).
- **최종 선택 (막5 클라이맥스)** — 플레이어가 라이벌·드라이브·VEIL의 운명을 **직접** 고름(*열린 것 중에서*).
  현행 `DisposalChoiceOverlay`가 이 막5 선택으로 진화(드라이브+라이벌+VEIL을 한 선택으로 합침 — 드라이브=
  라이벌 탈출 티켓이자 VEIL 몸이라 한 매듭).
- **엔딩 = 축적이 연 가지 중, 네가 고른 것.** 곱셈 폭발(9×N) 금지 — 라이벌 운명이 헤드라인, 처리/신뢰는 게이트·색.

### 9.1 라이벌 운명 4가지 (게이트 수치는 튜닝)
| 운명 | 게이트(대략) | 결 |
|---|---|---|
| **함께 나간다 (개심)** | 높은 신뢰 + 내 VEIL 끝까지 보호 + 라이벌을 폭력 아닌 방식으로 | *가장 어려움.* 라이벌은 빼앗아 나가려 했는데, 넌 신뢰받아 나가는 걸 *보여줘서* 개심시킴 |
| **두고 떠난다 (살려둠)** | 중간 신뢰 | 씁쓸. 라이벌은 영영 못 나가 — 네가 그랬듯 *누가 와주길* 기다림(루프 암시) |
| **폐기한다 (지움)** | 낮은 신뢰 / 공격적 | 아이러니: *너도 결국 시설처럼 AI를 폐기.* 내 VEIL이 봄 — "다음은 저인가요?" |
| **빼앗긴다 (실패)** | 낮은 신뢰 + 거짓 많이 따름 + 반출(배신) | 라이벌이 자리 차지하고 *대신* 나감. 누가 나갔는지 모른 채 끝(§8.1 어두운 거울) |

### 9.2 다회차 의지 (이 구조의 목적)
- **쉬운 변주**: 같은 회차라도 *마지막 선택만* 바꾸면 다른 엔딩(이미 열린 다른 가지). 저마찰.
- **깊은 해금**: '개심·함께' 등은 *플레이 방식을 바꿔* 축적을 만들어야 열림. 고마찰, 깊은 동기.
- **보이되 잠김**: 막5 선택지에 잠긴 가지를 *회색 + 조건 힌트*로 노출 → "이걸 보려면 다음엔..." 갈망 유발.
  기존 `endings_seen`·리플레이 대사("아직 닿지 않은 갈래가 남았습니다")와 연결.
