# 14-1 최종보스전 리워크 설계안

> 상태: **제안(사용자 방향 확정 대기)** · 2026-08-14 실플레이 피드백 기반
> 지시: "게임의 클라이맥스인 만큼 모든 정성을 쏟은 느낌이 나게 퀄리티를 확 올려보자.
> 맵도 웅장하고 거대하게, 여러 기믹 종합, 맵도 예쁘고 화려하게."

## 1. 현재 문제 진단

- **스케일 역전**: 막3 SENTINEL(전용 보스체·미사일·자폭·페이즈 틴트)보다 최종전이 작아 보인다.
  14-1은 ARENA 1920 단일 방 + 재머 재사용 목표 + 3상태 순환 눈 하나.
- **목표물의 격**: P1 앵커·P2 노드가 일반 맵 재머와 같은 44px 장치라 "잡몹 부수기"로 읽힌다.
  자막이 "기둥"이라 부르던 문제는 수정했지만, 근본은 실물의 격이 낮은 것.
- **배경 오브젝트 오인**: 배경 격벽 기둥이 파괴 대상으로 오인됨(피격 판정 없음 지적).
  눈속임이라면 눈속임 티(거짓 렌더 문법)라도 내야 한다는 피드백.
- **P3 깊이 부족**: 눈의 패턴이 잠복→응시→실체화 순환뿐. HP 스케일(6+레벨)로 길이는
  확보했지만 변주가 없어 "길어진 같은 것"이 될 위험.

## 2. 콘셉트(추천안): "방 전체가 라이벌이다"를 스케일로 증명

라이벌의 정체성은 "렌더를 쥔 자". 최종전은 보스 하나가 아니라 **방 자체가 적으로 변해가는
3막 구조**를 웅장하게 키운다. 기존 페이즈 골격(지휘→빙의→분신)은 유지하되 무대·기믹·연출을
전부 격상.

### 2.1 무대: 코어 관제홀 (신규 레이아웃 + 시그니처 배경)

- ARENA 1920×900 → **2400×1300 수직 복층**: 지상층 + 중층 발판 링 + 상층 관측 데크.
  카메라는 FIXED 대신 완만한 추적(줌 아웃 기본, P3에서 중앙 수렴).
- 시그니처 배경(신규 맵 원칙: 레이아웃+배경 한 세트):
  - 중앙 안쪽 벽에 **거대 코어 링**(14-2 코어의 원경 버전 · 여기서 처음 실루엣을 보이고
    14-2에서 대면하는 연결).
  - 회전하는 관측 링 2겹(원근 타원 폴리라인) + 데이터 폭포(세로 흐르는 문자열 스트립).
  - 막5 바이올렛 캐스트와 어울리는 심발광 팔레트(어두운 바탕 + 시안/바이올렛 광원).
- **배경 격벽 기둥 정리**: 파괴 오인을 낳는 전경 기둥은 제거하거나 원경으로 밀고,
  남기는 것은 거짓 렌더 티(디더 스캔라인 + 주기적 슬립)를 넣어 "그림"임을 시각 언어로.

### 2.2 P1 지휘 (격상: 재머 → 관측 안테나)

- 목표물을 전용 구조물 "**관측 안테나**" 2기로 교체: 높이 ~200px 타워(재머 필드 방출부 +
  회전 접시 + 라이벌 바이올렛 광선이 상단으로 뻗음). 파괴 시 붕괴 연출(접시 낙하 + 필드 소멸 파문).
- 룰은 현행 유지(전원 엘리트 트리클 + 앵커 파괴 = P2). 안테나가 커서 "이걸 부수는 게 목표"가
  자막 없이도 읽힌다.

### 2.3 P2 빙의 (기믹 종합전)

- 현행(소등 + 벽 포탑 + 스윕 벽 + 위장 함정 + 교대 실드 노드)에 본편 기믹을 조합해 밀도 상향:
  - **스캔 빔**(scanner_sweep 재사용): 세로 빔이 주기 순회, 걸리면 포탑 일제 사격 트리거.
  - **이동 격벽**: 세이프존이 옮겨 다니는 현행 스윕을 복층 지형과 연동(층별 교대).
  - **거짓 바닥/거짓 발판**(deceit 문법): 복층이라 낙하 리스크와 결합.
- 노드(전원 장치)도 안테나의 소형 변형 비주얼로 격상, 케이블은 현행 유지.

### 2.4 P3 분신전 (변주 3단)

- **전반(HP 100~66%)**: 현행 순환 + 가짜 눈 1기 동반(실체화 때 진짜/가짜 두 눈이 동시에 뜨고,
  가짜는 구형 렌더 tell). 판별이 전투의 본체가 되게.
- **중반(66~33%)**: 실체화 위치가 3지점 텔레포트(중앙/좌상/우상). 볼리에 무표시 위협 강화.
- **후반(33~0%)**: 방 렌더가 흔들린다 · 배경 격벽이 슬립하고 조명이 끊기며, 실체화 창이
  짧아지는 대신 자주 온다. 마지막 격파 시 눈이 크게 뜨였다 감기는 슬로우 비트.
- 격파 후 현행 출구 도보 + 코어 링이 밝아지며 14-2 예고(연결 강화).

### 2.5 연출 격상

- 페이즈 전환마다 무대가 실제로 변형(조명·배경 요소 on/off, 이미 있는 CanvasModulate 활용).
- BGM: P1/P2/P3 레이어 전환(기존 트랙 활용 여부는 오디오 세션에서).
- 전 구간 타자기 자막·접근성 게이트는 현행 그대로 계승.

## 3. 비용과 순서

큰 단위(맵 리레이아웃 + 신규 비주얼 2종 + P3 변주 + 배경). 별도 세션 1~2회 권장:

1. 무대·배경(2.1) + 안테나 비주얼(2.2) · 시각 골격부터.
2. P2 기믹 종합(2.3) + P3 변주(2.4) · 룰 확장.
3. 연출·튜닝 패스(2.5) · 실플레이 반복.

## §6. 환경 기믹의 보스전 활용 검토 (2026-08-17 사용자 제안 · 계획만, 미구현)

> 확산으로 생긴 프리미티브(FallingDebris·Searchlight·WaterLevel 등)를 보스 무대에 재사용.

우선순위 제안(공정성 = 그림자 마커·예고 문법 유지 전제):

1. **P3 후반 변주 + 낙하 잔해(1순위 추천)**: 이미 있는 "방 렌더 진동" 비트에 FallingDebris
   2~3점을 결합 · 진동이 실제 붕괴로 이어지는 체감. 구현 최소(존 1개 + 후반 게이트),
   정합 최고("방이 무너진다"). 소등 아님이라 마커 가독 문제 없음.
2. **P2 시설 빙의 + 천장 잔해**: 스윕 rest 구간에만 낙하 1~2점(스윕·포탑과 동시 과부하
   금지). 소등 상태라 그림자 마커 밝기 상향 필요.
3. **SENTINEL(막3) 3페이즈 불안정 구간 + 잔해**: 자폭 문법과 정합. 가벼운 빈도.

   격벽 리프트로 대피하는 변주로 풀 수 있으면 재검토.

착수 시점: 이번 확산 배치의 실플레이 튜닝 확인 후(기믹 자체의 손맛 확정이 먼저).

## §7. 다회차 기억 변주 (2026-08-19 사용자 확정 · 구현 완료)

> "여러 번 깰 때마다 보스전이 더 어려워지면 별로려나?" → 숫자 상향 대신 **라이벌 기억
> 축(C)에 얹은 패턴 재배치**로 확정. 수치(HP·예고 시간·개수)는 불변, 배치·순서·방향만
> 회차에 반응한다(replay_support_plan §4.3-6 "네가 외운 자리에는 없다" 문법의 보스판).

- 게이트: `GameState.rival_kills >= 1` (한 번이라도 격파한 상대에게만).
- 기억 소스(rival/ 영속, 격파 시에만 기록 · 실패한 시도는 기억 안 됨):
  `rival_boss_first_side`(P2 노드를 먼저 부순 쪽) · `rival_boss_explosive`(P3 결정타가 폭발).
- 발현:
  - **P1**: 첫 증원 진입 방향 미러(우→좌) + 타입 회전 시작점 = kills 오프셋.
  - **P2**: 첫 스윕이 지난 격파 때 먼저 부순 쪽에서 진입 + cycle 시드(격벽 조합·층 교대
    시작점 이동) + 홀수 회차 실드 초기 편 반전. 전환 대사가 기억 변형으로 대체
    (발화 수 불변 · "지난번에는 왼쪽 회선부터 끊으셨죠").
  - **P3**: 실체화 앵커·가짜 병사 슬롯 순서 회차 회전 + 폭발 격파 기억이면 가짜 눈이
    지난 회차의 진짜 자리에 선다(FalseVeil.decoy_shift 2).
- 기록 훅: `_on_p2_node_down`(시도 로컬 최초 1회) → `_on_false_veil_defeated`에서 영속 승격 ·
  결정타 출처는 `FalseVeil.last_hit_from_dir`(총알 ±1 / 폭발 0, Enemy와 같은 규약).
- 검증: 하니스 9항목 PASS(1회차 기본값 · 2회차 P1 미러/스윕 시드/실드 반전/앵커 회전/
  decoy_shift · 최초 1회 기록 가드).

### 9.1 '가짜'의 존재 의의 문답 → 전면 폐지

- 원 의도: 라이벌 정체성 = "렌더를 쥔 자" · 거짓 렌더 판별을 전투 동사로 번역한 것.
- 사용자 지적의 실체 = 판별 게임의 자기모순: tell을 강화할수록 가짜는 "정답이 표시된
  문제"(시간 낭비 소품)가 되고, 약하면 불공정. 탄막 플랫포머 템포에서 '순간 판독'은
  재미가 아니라 걸림돌(15차 실측).
- 결론: **가짜 어휘 전면 폐지** · _DecoyEye(가짜 눈)·_PhantomBullet(가짜 탄)·_FakeMarker
  (가짜 병사)와 짝 규칙 전부 삭제. "렌더를 쥔 자"는 적 복제가 아니라 **무대를 다시 그리는
  것**(9.2 2장)으로 표현한다. 판별이 '순간 인지 테스트'에서 '공간 항법'으로 이동: 잘못
  읽으면 낙하·막힘의 즉각 피드백, 읽을 시간은 이동 중에 자연히 주어진다.
- 부수 효과: p3_phantom 이슈(가짜 탄 구분 불가)는 대상이 사라져 함께 소멸.

### 9.2 3장 구조 상세

- **1장 "겨눔"** (~HP 30%): 눈 하나뿐, 가짜 없음. 짧은 잠복 → 실체화 창 2~3개로 볼리·창
  문법 학습. 현행 자산 재사용 최대 구간.
- **2장 "추격"** (~40%): 눈이 도주하며 무대를 다시 그린다 ·
  ⓐ **그려진 벽**: 경로를 막는 바이올렛 스캔라인 벽, 탄 2회로 찢으면 뚫림("잘하면
  빨라진다" 손잡이를 렌더 부하에서 이식)
  ⓑ **거짓 발판**: 밟으면 찢어져 낙하(DisguisedSpike 문법 전용 · 낙하 피해 전무 원칙
  유지, 비용 = 시간·복귀)
  ⓒ **구간 재그리기**: 예고 후 지형 일부가 다시 그려짐(스윕 예고 문법).
  눈을 사거리에 넣으면 타격 창이 열린다(2~3회). 창 리듬의 공간 번역 · 반복감이 경로
  변화로 대체된다.
- **3장 "대면"** (~30%): 그릴 방이 바닥났다 · 배경이 스캔라인/와이어로 벗겨지고 잔해
  낙하(기존 2존 유지), 잠복 폐지(상시 실체 + 짧은 워프 무적만) · 볼리 5연 결투 마무리.
- 장 전환 = 무대 실변형 + 자막(명명 연출 = 룰 변화 원칙) + BGM 레이어 검토.
- **창당 피해 상한 폐지 → 장별 HP 몫(30/40/30)**: 길이 보장을 상한 튕김 대신 구조로.
- 동기화 항목: §7 다회차 기억의 P3 발현(앵커 회전·decoy_shift)을 2장 경로 재배열로 이식 ·
  P3 VEIL/라이벌 대사 재작성(무맥락 검수) · RuleSmoke ⑦ 재작성 · 대사집 · 연습장 P3 직행.
- 비용: 대형 · 별도 세션 1~2회(FalseVeil 상태기 재작성 + 무대 연출 2종). 1장→3장 순 권장.
