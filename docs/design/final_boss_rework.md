# 14-1 최종보스전 리워크 설계안

> 상태: **제안(사용자 방향 확정 대기)** · 2026-08-14 실플레이 피드백 기반
> 지시: "게임의 클라이맥스인 만큼 모든 정성을 쏟은 느낌이 나게 퀄리티를 확 올려보자.
> 맵도 웅장하고 거대하게, 여러 기믹 종합, 맵도 예쁘고 화려하게."

## 1. 현재 문제 진단

- **스케일 역전**: 막3 SENTINEL(전용 보스체·미사일·자폭·페이즈 틴트)보다 최종전이 작아 보인다.
  14-1은 ARENA 1920 단일 방 + 재머 재사용 목표 + 3상태 순환 눈 하나.
- **목표물의 격**: P1 앵커·P2 노드가 일반 맵 재머와 같은 44px 장치라 "잡몹 부수기"로 읽힌다.
  자막이 "기둥"이라 부르던 문제는 수정했지만, 근본은 실물의 격이 낮은 것.
- **배경 오브젝트 오인**: 배경 격벽 기둥이 파괴 대상으로 오인됨(피격 판정 없음 지적).
  눈속임이라면 눈속임 티(거짓 렌더 문법)라도 내야 한다는 피드백.
- **P3 깊이 부족**: 눈의 패턴이 잠복→응시→실체화 순환뿐. HP 스케일(6+레벨)로 길이는
  확보했지만 변주가 없어 "길어진 같은 것"이 될 위험.

## 2. 콘셉트(추천안): "방 전체가 라이벌이다"를 스케일로 증명

라이벌의 정체성은 "렌더를 쥔 자". 최종전은 보스 하나가 아니라 **방 자체가 적으로 변해가는
3막 구조**를 웅장하게 키운다. 기존 페이즈 골격(지휘→빙의→분신)은 유지하되 무대·기믹·연출을
전부 격상.

### 2.1 무대: 코어 관제홀 (신규 레이아웃 + 시그니처 배경)

- ARENA 1920×900 → **2400×1300 수직 복층**: 지상층 + 중층 발판 링 + 상층 관측 데크.
  카메라는 FIXED 대신 완만한 추적(줌 아웃 기본, P3에서 중앙 수렴).
- 시그니처 배경(신규 맵 원칙: 레이아웃+배경 한 세트):
  - 중앙 안쪽 벽에 **거대 코어 링**(14-2 코어의 원경 버전 — 여기서 처음 실루엣을 보이고
    14-2에서 대면하는 연결).
  - 회전하는 관측 링 2겹(원근 타원 폴리라인) + 데이터 폭포(세로 흐르는 문자열 스트립).
  - 막5 바이올렛 캐스트와 어울리는 심발광 팔레트(어두운 바탕 + 시안/바이올렛 광원).
- **배경 격벽 기둥 정리**: 파괴 오인을 낳는 전경 기둥은 제거하거나 원경으로 밀고,
  남기는 것은 거짓 렌더 티(디더 스캔라인 + 주기적 슬립)를 넣어 "그림"임을 시각 언어로.

### 2.2 P1 지휘 (격상: 재머 → 관측 안테나)

- 목표물을 전용 구조물 "**관측 안테나**" 2기로 교체: 높이 ~200px 타워(재머 필드 방출부 +
  회전 접시 + 라이벌 바이올렛 광선이 상단으로 뻗음). 파괴 시 붕괴 연출(접시 낙하 + 필드 소멸 파문).
- 룰은 현행 유지(전원 엘리트 트리클 + 앵커 파괴 = P2). 안테나가 커서 "이걸 부수는 게 목표"가
  자막 없이도 읽힌다.

### 2.3 P2 빙의 (기믹 종합전)

- 현행(소등 + 벽 포탑 + 스윕 벽 + 위장 함정 + 교대 실드 노드)에 본편 기믹을 조합해 밀도 상향:
  - **스캔 빔**(scanner_sweep 재사용): 세로 빔이 주기 순회, 걸리면 포탑 일제 사격 트리거.
  - **이동 격벽**: 세이프존이 옮겨 다니는 현행 스윕을 복층 지형과 연동(층별 교대).
  - **거짓 바닥/거짓 발판**(deceit 문법): 복층이라 낙하 리스크와 결합.
- 노드(전원 장치)도 안테나의 소형 변형 비주얼로 격상, 케이블은 현행 유지.

### 2.4 P3 분신전 (변주 3단)

- **전반(HP 100~66%)**: 현행 순환 + 가짜 눈 1기 동반(실체화 때 진짜/가짜 두 눈이 동시에 뜨고,
  가짜는 구형 렌더 tell). 판별이 전투의 본체가 되게.
- **중반(66~33%)**: 실체화 위치가 3지점 텔레포트(중앙/좌상/우상). 볼리에 무표시 위협 강화.
- **후반(33~0%)**: 방 렌더가 흔들린다 — 배경 격벽이 슬립하고 조명이 끊기며, 실체화 창이
  짧아지는 대신 자주 온다. 마지막 격파 시 눈이 크게 뜨였다 감기는 슬로우 비트.
- 격파 후 현행 출구 도보 + 코어 링이 밝아지며 14-2 예고(연결 강화).

### 2.5 연출 격상

- 페이즈 전환마다 무대가 실제로 변형(조명·배경 요소 on/off, 이미 있는 CanvasModulate 활용).
- BGM: P1/P2/P3 레이어 전환(기존 트랙 활용 여부는 오디오 세션에서).
- 전 구간 타자기 자막·접근성 게이트는 현행 그대로 계승.

## 3. 비용과 순서

큰 단위(맵 리레이아웃 + 신규 비주얼 2종 + P3 변주 + 배경). 별도 세션 1~2회 권장:

1. 무대·배경(2.1) + 안테나 비주얼(2.2) — 시각 골격부터.
2. P2 기믹 종합(2.3) + P3 변주(2.4) — 룰 확장.
3. 연출·튜닝 패스(2.5) — 실플레이 반복.
