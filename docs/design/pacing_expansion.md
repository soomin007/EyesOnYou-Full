## 1. 레버 1 — 맵 길이 + 중간 관문

- **길이**: 막2+ 통과형(HORIZONTAL) 맵의 `world_size.x`를 현행 3800~4400 → **6000~7000**(약 1.6배).
  배경·소품은 대부분 STAGE_LENGTH 기반 절차 생성이라 따라오지만, **좌표 하드코딩 요소**
  (로어 라벨·시그니처 소품·비밀칸·게이트)는 맵별 재배치 검수 필수.
- **중간 관문 문법 3종**(맵 정체성에 맞춰 택1, 맵당 1개):
  - ⓐ **격벽+동력 레버**: 잠긴 격벽 앞 전투 구간. 레버(또는 재머 파괴)로 개방. 기존
    LeverInteractable·게이트 재사용. 통과형 기본값.
  - ⓑ **2구획 구조**: 전반 잠입/통과 → 관문 방에서 국소 전멸 조건(그 방의 적만) → 후반.
    "모든 적과 싸울 필요 없다" 정체성은 유지 — 전멸은 관문 방 한정.
  - ⓒ **기믹 리듬 연장**: 기믹 맵은 사이클 수 확대(스캐너 니치 +2, 리프트 왕복 +1,
    추격 구간 연장, 저지선 웨이브 +1). 새 문법 불필요, 수치만.
- **검수 함정**(known_issues 기존 항목 준수): 발판 점프 등급(S/D) · ENEMY_CLEAR 도달 보장 ·
  트랩은 주 동선 교차 · 재머 반경과 안전지대 · 관문 레버는 안전 발판 위.

## 2. 레버 2 — 적 밀도·웨이브

- 통과형 맵 적 수 = 길이 비례 상향 + 관문 구간 **미니 웨이브 1회**(증원 텔레그래프 재사용).
- 만렙 녹임 대응: 막3+ 엘리트 비율 상향, 클러스터 대신 사선 분산 배치(관통 한 방 몰살 방지 —
  보스 재설계 때 확립한 원칙의 일반화).
- 밀도는 **압력**이지 전멸 조건이 아니다(ⓑ 관문 방 제외). 우회 플레이는 계속 유효해야 한다.

## 3. 작업 순서 (별도 세션 1~2회)

1. **파일럿 = 막2 4맵**: 통과형 2(pump_station·checkpoint) + 기믹 2(freight_lift·scanner_sweep).
   길이 1.6배 + 관문(ⓐⓐ/ⓒⓒ) + 밀도. 하니스(완주 보장·점프 등급·좌표 검수) + 스크린샷.
2. **실플레이 실측**: `[RUN]` 맵별 소요가 90~120초 범위인지. 어긋나면 계수 조정.
3. **확산**: 합격 문법을 막2~5 전 통과형·기믹 맵에 적용(맵당 정체성 맞춤). 막1은 마지막에 소폭.
4. **연동 항목**: 14-1 체감 길이는 `final_boss_rework.md`(결정 대기)가 담당. VEIL 유대 잡담은
   체류 시간이 생긴 뒤(관문 대기·정적 구간이 잡담 슬롯이 된다).

## 4. C(스테이지 모디파이어) — 다회차 전용으로 보류

사용자 유보(2026-08-15: "몰입에 도움이 될지 모르겠다, 다회차용이 낫지 않나") 수용:
- **1회차는 순수 유지** — 저작된 서사 몰입을 조건 변주로 흔들지 않는다.
- 모디파이어는 **완주 후(다회차·재진입 런) 전용** 후보로만 설계한다. 서사 근거가 정확히 있다:
  lore_expansion §2.1 "관측은 반복된다. **조건을 조금씩 바꿔** 같은 임무가 다시 굴려진다" —
  2회차부터 루트 카드에 관측 조건이 붙는 것은 세계관의 기계화다(예: "정전 구역 · 보상 +50%",
  "관측 강화 · 감시 장비 2배 · 단일 기록 2배").
- 상세 설계·구현은 페이싱 확산 완료 후 별도 논의(backlog 등재만).
