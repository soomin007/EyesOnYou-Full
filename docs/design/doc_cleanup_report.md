## 3. 판단 보류 목록 (사용자 결정 필요)

지시서상 "역할 종료가 명시적으로 확인되는 경우에만 이동" 기준에 걸려 **옮기지 않은** 항목이다.
셋 다 "구현은 끝났으나 다른 문서가 현역으로 참조 중"이라는 같은 성격의 충돌이다.

### ① `veil_trust_arc.md` · `veil_pool_remap.md`: 이동 보류
- **상태**: 두 문서 모두 머리에 ✅ 구현됨(2026-06-13) 표기. 지시서 아카이브 후보 목록에 있음.
- **보류 이유**: INDEX **단일 소스 지도에 등재**돼 있고(VEIL 어투·엔딩 점수 축·취약함 게이트 / 대사 grid),
  `README.md`·`SPEC.md`·`STORY.md` §3이 현역으로 링크한다. archive는 규칙상 "참조 금지"라
  옮기면 단일 소스가 참조 금지 구역에 놓이는 모순이 생긴다. backlog A에 신뢰 임계 튜닝도 살아 있다.
- **선택지**: ⓐ 그대로 유지(현행) / ⓑ archive로 옮기고 어투·밴드 grid의 단일 소스를 STORY.md로 흡수
  (흡수는 내용 판단이 필요한 작업이라 이번 범위 밖).

### ② `veil_replay_dialogue.md`: 이동 보류
- **상태**: 다회차 대사 변형 제안. 3축 설계(`replay_support_plan.md`)로 **승격**됐다고 backlog에 기록됨.
- **보류 이유**: 문서의 본래 과제("채택할 후보에 표시해주면 배선한다")가 **아직 미완**이고, backlog 본문에도
  "사용자 검토 후 채택분 배선"이 남아 있다. `replay_support_plan.md`가 대사 톤 원칙 출처로 참조 중.
- **선택지**: ⓐ 검토를 `dialogue_review.md`로 합치고 이 문서는 archive / ⓑ 검토 완료 때까지 유지(현행).
