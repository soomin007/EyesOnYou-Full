> 로그 2026-08-17 참조).

## 1. 진단 · 무엇이 지루했나

기존 다수 맵 = **등간격 메트로놈**: 같은 폭(180~220)의 발판이 같은 높이(y460~480)에
~500px 간격으로 반복. 리듬 그룹도, 기승전결도, 랜드마크도 없는 "무한 복도"라 어느 맵을
걸어도 손이 같은 일을 한다. 시그니처 해저드(정체성 기믹)가 있어도 **지형이 같으면 절반만
다른 맵**이다.

## 2. 수칙 6 (전 맵 공통)

1. **리듬 그룹**: 발판·해저드를 "악구"로 묶는다 · 시작·전개·마침이 있는 클러스터
   (2~4개 요소) + 클러스터 사이 **휴지(빈 지면 300~500px)**. 등간격 나열 금지.
   맵 하나 = 악구 3~5개.
2. **기승전결(맵당 4비트)**: 기 = 정체성 기믹을 안전하게 보여주기(초반 300~700px,
   이미 route_lines·첫 조우 선행으로 구현됨) / 승 = 기믹 + 적 결합 / 전 = 기믹의 변주
   또는 최대 밀도(세트피스) / 결 = 골 앞 이완(위협 없는 마지막 300px).
3. **높이 변주**: 한 줄 발판 금지. 맵당 최소 1개의 **2층 구간**(상하 경로 선택)과
   1개의 **저단차 스텝**(y510~530)을 섞는다. 점프 등급은 유지: S=Δ≤95 / D=Δ~130 /
   Δ160+ 금지.
4. **리스크-리워드 포켓**: 맵당 1~2개, 메인 동선 밖(위층·기믹 위험 곁)에 보상을 두되
   왕복 비용이나 위험이 명확해야 한다. 공짜 파밍 금지(경보 진압 경비 = 무보상과 동결).
5. **랜드마크 1개**: 맵마다 기억에 남는 지형 세트피스 1개(계단식 잔해 산, 2층 데크,
   상부 코일 등). "그 맵 어디였지?"에 답이 되는 장소.
6. **기믹-지형 결합**: 시그니처 해저드가 지형과 얽혀야 한다(아크 위를 발판으로 넘기,
   잔해 존 안의 계단 등반, 벨트 탄력 점프). 해저드가 평지에 그냥 놓이면 절반 낭비.
